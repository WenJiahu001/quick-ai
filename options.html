快捷AI

选中文字后，从右键菜单选择提示词，将内容发送给当前 AI 服务商。

AI 服务商
使用当前填写的配置发送一次简短 AI 请求，可能产生少量费用；不会自动保存。

只保存 AI 服务商及当前选中项。
提示词
禁用的提示词不会出现在右键菜单。修改后点击下方按钮保存。
只保存提示词列表和启用状态。
选中文字清理规则
按列表顺序区分大小写地匹配文字，并替换所有匹配项。可替换为空格、换行或自定义内容；清理后的题目会显示并发送给 AI。
只保存选中文字清理规则。

配置备份

导出当前页面中的提示词、清理规则和服务商配置，不包含 API Key。导入后会载入页面，分别到对应选项卡保存才会生效。

API Key 不会写入备份文件。导入后，仅 ID 和 API 地址均相同的服务商保留本机 API Key；新增服务商或地址变更后需要重新填写。

初次请求发送所选提示词和清理后的选中文字；追问还会发送本次对话的完整历史。内容发送给当前选中的 AI 服务商，不会读取整页内容。
