# 发布检查清单

本清单记录需要人工执行的浏览器回归，不代表这些场景已经通过。静态检查不执行扩展业务，也不发送 AI 请求。

## 构建与更新

- 运行 `node scripts/check.mjs`、`node scripts/package.mjs`、`node scripts/check.mjs --package`。
- 用 Edge、Chrome 分别加载 `dist/chromium/`，确认设置页可读取、保存配置。
- 更新时先替换文件，再重新加载扩展，最后刷新网页。旧网页应给出明确的重新加载提示。
- 执行 `scripts/create-release-assets.ps1` 生成 ZIP 与 SHA256；核对版本、提交和附件，避免发布旧包。

## 请求生命周期

- 首轮、多轮追问、编辑任意追问和失败重试；确认用户消息没有重复、未完成回复不进入上下文。
- 连接前、等待首字、生成中和渲染积压时停止；确认保留部分回复和草稿。
- 模拟后台停止、连续 15 秒无文字、超过两分钟等待；确认不会无限等待或自动重发。
- 刷新、跳转、关闭标签页、连续选择新题；确认旧请求取消且不会向新文档投递。

## 显示与性能

- 长表格、嵌套列表、长段落、超过 25 万字符的回复；确认可拖动、隐藏、关闭。
- 生成中隐藏、切到后台再恢复；确认继续收取数据、恢复后增量补齐 Markdown。
- 折叠旧回复后展开；确认样式和文字一致，后续请求上下文完整。
- 隐藏后缩小窗口，确认“快捷AI +”始终可点击；小尺寸窗口中回复和操作区可用。
- 复制后立即追问或触发错误，确认复制反馈不会覆盖请求状态。
- 手动开启本页性能诊断，观察耗时和节点数量；关闭后不继续统计。

## 配置与边界

- 多提示词的启用、常用、排序、复制和删除；确认展开状态、焦点和未保存提示正确。
- 修改后恢复原值、搜索和展开列表，确认只有真实修改标记为未保存。
- 配置读取失败时禁止保存；恢复读取后可继续编辑。
- 两个设置页修改同一区块，后保存者应收到冲突提示；不同区块可独立保存。
- 导入超过 2 MB 文件、超过 500 项配置及导致文字快速膨胀的清理规则，应给出明确错误。
- 检查浮层仅通过白名单消息访问外观和窗口设置，无法读取服务商和 API Key。

## 发布记录

发布时记录浏览器版本、已执行项目和未覆盖项目。真实服务请求可能产生费用，应使用专用测试服务或明确授权的配置；不要将密钥、选区或回复内容写入诊断记录。
