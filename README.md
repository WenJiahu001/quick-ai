# 快捷AI

一个面向 Edge 桌面版的 Manifest V3 扩展。选中网页文字后，右键打开“快捷AI”子菜单，手动选择一组提示词。扩展将所选文字和该提示词发送给配置的 AI 服务，并在当前网页显示流式 Markdown 回复。提示词在顶部默认折叠，选中文字固定显示在其下方；回复区域单独滚动，浮层也可拖动右下角调整大小。

## 安装

1. 打开 Edge，进入 `edge://extensions`。
2. 打开“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中本项目目录。
4. 打开扩展的“扩展选项”，填写 API Key、模型和提示词。
5. 选中普通网页中的一段文字，右键在“快捷AI”子菜单中选择提示词。

默认模型为 `gpt-6-luna`，默认 API 地址为 `https://api.openai.com/v1`。扩展通过 OpenAI 兼容的 Chat Completions 接口（`/chat/completions`）通信，因此也可配置提供该兼容接口的其他 AI 服务；在设置页填写服务根地址、模型名称和对应的 API Key 即可。服务需要兼容 Bearer Key 认证、Chat Completions 消息格式和流式 SSE 返回。原生 Anthropic、Gemini 等非兼容协议暂不支持。提示词可在设置页添加、编辑和删除；保存后右键菜单会更新。Base URL 可使用 HTTP 或 HTTPS，保存时 Edge 会请求对应站点权限。

从旧版升级后，请打开一次扩展设置并保存，以授权当前 AI 服务的网络访问权限。旧的 `OPENAI_BASE_URL` 会自动读取并在保存时迁移为通用 Base URL。

## 数据处理

API Key 保存在当前 Edge 配置的扩展本地存储中，由扩展后台用于请求，不会传入网页脚本。请求只包含选中文字、所选提示词和模型；扩展不读取整页内容，也不保存回复历史。浏览器扩展本地存储不提供额外加密。

使用 HTTP 时，API Key 和请求内容会以明文传输，可能被网络中的其他人读取。只应对可信的本机或内网服务使用 HTTP。
